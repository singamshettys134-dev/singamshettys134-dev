## Featured project

### [PrescripTrack](https://github.com/singamshettys134-dev/Tata1mg_kalvium-community)
Prescription-to-order tracking platform for doctors and pharmacies. Built with my team for Kalvium SPE Squad-134.

- Next.js 14 (App Router) with **23 API route files** covering auth, doctor and pharmacist workflows
- **PostgreSQL + Prisma**, with a 31-model schema, migrations and seed data
- JWT sessions, Google OAuth and **role-based Edge middleware**
- Zod validation, security headers, and transactional prescription status rules

`Next.js` `React` `TypeScript` `Tailwind CSS` `Prisma` `PostgreSQL` `JWT` `Zod`
